Research Projects

tamuBO — Bayesian Optimization Toolkit

A multi-framework Bayesian optimization library developed at Texas A&M. Includes exact expected-improvement search with partition-based bounds, BoTorch-based workflows, GPU-oriented GP components, and multi-objective BO utilities.

Focus: surrogate modeling, uncertainty quantification, adaptive experimental design.  ·  GitHub →

MaterialNet — Semantic Network for Materials

Builds a knowledge graph of materials, their functions, and potential applications from the MaterialDistrict database (3,163 materials). Uses LLMs to extract structured triples and Sentence-BERT embeddings to compute semantic similarity edges.

Focus: knowledge graphs, LLM-assisted extraction, materials informatics.  ·  GitHub →  ·  Live App →

CMS3 — Large DDD Model VR Visualization

A-Frame WebXR scene for real-time visualization of large discrete dislocation dynamics (DDD) simulation outputs directly in the browser.

Focus: scientific visualization, WebXR, large-scale simulation data.  ·  GitHub →  ·  Live Demo →
